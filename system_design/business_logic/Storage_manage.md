# Storage Management

## 1. Input (ข้อมูลนำเข้า)
- ไฟล์เสียงจาก Audio Upload Management
- Audio ID
- User ID / Session ID
- คำขอจัดการไฟล์ (อัปโหลด / เรียกดู / ลบ)

## 2. Rule (เงื่อนไข)
- ผู้ใช้ต้องผ่านการยืนยันตัวตน
- ผู้ใช้เข้าถึงได้เฉพาะไฟล์ของตนเอง
- ไฟล์ต้องเป็นรูปแบบที่ระบบรองรับ
- การลบไฟล์ต้องผ่านการตรวจสอบสิทธิ์ก่อนดำเนินการ

## 3. Process (กระบวนการ)
1. รับคำขอจัดการไฟล์จากระบบ
2. ตรวจสอบ Session และสิทธิ์ของผู้ใช้
3. ตรวจสอบตำแหน่งและข้อมูลไฟล์ใน Storage
4. ดำเนินการอัปโหลด เรียกดู หรือลบไฟล์
5. เก็บ Audio path ไว้ใน database เพื่อให้เรียกใช้ได้
6. อัปเดตสถานะและข้อมูลที่เกี่ยวข้องใน Database 

## 4. Output (ข้อมูลส่งออก)

**กรณีสำเร็จ**
- Audio ID
- ตำแหน่งจัดเก็บไฟล์ (Storage Path)
- สถานะการดำเนินการ

**กรณีผิดพลาด**
- Error Code
- Error Message
- สถานะ: `Failed`
